# M4 — primer smoke test CNN causal (ingeniería, no resultado científico)

**Fecha:** 2026-10-22. **Estado:** ruta de entrenamiento técnica demostrada con fixtures sintéticos; D0–D5 para investigación siguen abiertos.

## Resultado observado en entorno de ejecución de ChatGPT

Se ejecutó un smoke test CPU con Keras 3.13.2 backend PyTorch 2.10.0+cpu y 24 escenas de entrenamiento + 8 de validación (todas artificiales), 6 épocas, seed 42. Modelo de 236,833 parámetros, con target embedding 16, Conv1D causal 128 filtros y dilataciones 1/2/4, salida 257-bin sigmoid.

| Check técnico | Resultado observado |
|---|---|
| Loss MSE del mismo conjunto de entrenamiento, antes | 0.2224257 |
| Loss MSE de entrenamiento, después | 0.0268957 |
| Última loss validación | 0.0283625 |
| Pesos modificados | Sí |
| Predicciones finitas y máscara dentro [0,1] | Sí |
| Inferencia sin stems en input | Sí |
| Reconstrucción STFT/iSTFT offline con ganancia aprendida | Sí |
| Fuente acústica real / voz real / validación científica | **No** |
| Frontend causal WOLA conectado / streaming / TFLite | **No** |

Estos números se refieren a un smoke test de software, **NO** a eficacia, generalización ni cumplimiento de RNF científicos. Solo se usaron ondas de tonos y chirps artificiales; la validación procede del mismo generador de escenas que entrenamiento. La prueba utiliza **MSE de máscara**, no la función L0 de PI7; D3 continúa abierto. El frontend emplea STFT centrada offline (boundary=zeros), NO el módulo causal WOLA para streaming.

## Repetir en Acer Nitro 5, Windows PowerShell

Desde la raíz del repositorio:

~~~powershell
cd 04_build/selective_audio_lab
py -3.11 -m venv .venv-m4-smoke
.\.venv-m4-smoke\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install "numpy>=1.26" "scipy>=1.12" "soundfile>=0.12" "keras>=3.10,<4" "torch>=2.7,<3"
python smoke_m4_keras_torch.py --out outputs/m4_cnn_smoke --epochs 6
~~~

Usar entorno nuevo separado de requirements-lock.txt porque los paquetes de DL requieren compatibilidad propia. No se agrega Torch al CI PI8 (evitar descargas pesadas obligatorias). PyTorch puede requerir instrucciones de instalación específicas para la GPU del equipo; este smoke trabaja en CPU. En otros entornos, la versión exacta y las métricas pueden variar.

Artefactos: m4_cnn_smoke_summary.json, smoke_input.wav y smoke_output.wav. El audio es ~0.31 segundos y no sirve como demo de atenuación de sirenas reales.

## Qué demostramos y qué sigue

**Demostrado:** formas tensoriales, gradiente/actualización de pesos, reducción de loss, inferencia sin stems, cálculo de ganancia a partir de máscara, reconstrucción audible/sintética, ejecutable en CPU.

**Pendiente antes de tesis experimental:** corpus con fuentes aisladas, hashes y licencias; train/val/test sin reuso de grabaciones; frontend STFT/OLA causal integrado; loss L0 estable con target-absent y variante de preservación prospectiva; checkpoint y test independiente sellado; evaluación A_target/A_protected/SI-SDRi pareada con Oracle; TFLite/paridad y benchmark real p95/hop/E2E.
