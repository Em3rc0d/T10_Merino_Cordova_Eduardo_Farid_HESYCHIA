# Evidencias PI8

Este directorio conserva evidencia ligera y reproducible del incremento PI8.

- `demo_summary.json`: resumen del run.
- `demo_metrics.csv`: A_target, A_protected, SI-SDRi y parámetros.
- `artifacts_manifest.csv`: checksums de artefactos binarios generados.
- `latency_summary.json` / `latency_samples.csv`: benchmark local.
- `demo_console_output.txt`: salida de consola.

Los WAV, la máscara NPY y las figuras se regeneran ejecutando el build. Las métricas de latencia son del entorno local de desarrollo; **no son medición del Honor X8c**.
